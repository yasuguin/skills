# ルールの最適化の事例

ルールを機械的な強制へ移したら、次に同じ判断をするときの手がかりとして 1 件ずつ残す。読むのは、移す先や
誤検出の対策で迷ったときだけ。

## 記録先

既定は `~/.local/state/agent-doctor/cases.md`（環境変数 `AGENT_DOCTOR_CASES` があればその場所）。
skill の中に書くと、skill を更新したときに上書きされるため外に置く。無ければこの型で作る。

## 型

```markdown
# <何を何へ移したか>（<日付>、<repo>）

## 発端
<どの prose のルールが守られなかったか・ずれていたか>

## 判断
<移す先と、選ばなかった先の理由>

## 誤検出の対策
<表面上似ているが許可すべき入力と、それをテストに入れたか>

## 教訓
<次に同じ判断をするときに効くこと>
```
